# FlowKey

[English](README.md) · [简体中文](README.zh-CN.md)

यह संक्षिप्त अनुवाद पुराने प्रोटोटाइप दस्तावेज़ की जगह लेता है, जिसमें ऐसी सुविधाओं के पूर्ण होने का दावा था जो वास्तव में लागू नहीं थीं।

FlowKey एक नेटिव macOS टेक्स्ट वर्कस्पेस है। वर्तमान executable Apple Translation से अनुवाद, योग्य सिस्टम पर Apple के ऑन-डिवाइस मॉडल से स्पष्ट rewrite actions, उपयोगकर्ता द्वारा शुरू किया गया dictation, स्थानीय terminology list, global Quick Action panel और वैकल्पिक InputMethodKit input source देता है।

FlowKey का अपना language server नहीं है और यह MLX, Whisper, iCloud sync या semantic knowledge base का दावा नहीं करता। Input source की स्थापना तथा Accessibility, Microphone और Speech Recognition permissions के लिए हमेशा उपयोगकर्ता की स्पष्ट कार्रवाई आवश्यक है।

वर्तमान आवश्यकताओं, build instructions और पूरी जानकारी के लिए [README.md](README.md) देखें।
