# FlowKey

[English](README.md) · [简体中文](README.zh-CN.md)

يحل هذا الملخص محل توثيق النموذج الأولي القديم الذي كان يدّعي اكتمال ميزات غير منفذة فعليًا.

FlowKey هو تطبيق macOS أصلي لتحويل النص بأقل عدد ممكن من الخطوات. يوفر الإصدار التنفيذي الحالي الترجمة عبر Apple Translation، وإجراءات إعادة كتابة واضحة عبر نموذج Apple الموجود على الجهاز عندما يكون النظام مؤهلًا، وإملاءً يبدأه المستخدم، وقائمة مصطلحات محلية، ولوحة Quick Action عامة، ومصدر إدخال InputMethodKit اختياريًا.

لا يضيف FlowKey خادم لغة خاصًا به، ولا يدّعي توفير MLX أو Whisper أو مزامنة iCloud أو قاعدة معرفة دلالية. يتطلب تثبيت مصدر الإدخال ومنح أذونات تسهيلات الاستخدام والميكروفون والتعرف على الكلام إجراءً صريحًا من المستخدم دائمًا.

توجد المتطلبات الحالية وتعليمات البناء والتوثيق الكامل في [README.md](README.md).
