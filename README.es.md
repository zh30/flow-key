# FlowKey

[English](README.md) · [简体中文](README.zh-CN.md)

Esta traducción resumida reemplaza la documentación histórica del prototipo, que afirmaba funciones que no estaban implementadas.

FlowKey es una aplicación nativa de macOS para transformar texto con el menor número posible de pasos. La versión ejecutable actual ofrece traducción mediante Apple Translation, acciones explícitas de reescritura mediante el modelo local de Apple cuando el sistema es compatible, dictado iniciado por el usuario, una lista local de terminología, un panel global de acciones rápidas y una fuente de entrada InputMethodKit opcional.

FlowKey no incluye un servidor de lenguaje propio ni afirma disponer de MLX, Whisper, sincronización con iCloud o una base de conocimiento semántica. La instalación de la fuente de entrada y los permisos de Accesibilidad, Micrófono y Reconocimiento de Voz siempre requieren una acción explícita del usuario.

La documentación mantenida, los requisitos y las instrucciones de compilación están en [README.md](README.md).
